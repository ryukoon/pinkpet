# 진행해줘 펫 🐔

갤럭시 폴드8 / S24 FE 홈 화면과 다른 앱 위를 돌아다니는 8bit 핑크 스웨터 펫.

## APK 만들기 (PC 프로그램 설치 필요 없음)

1. PC 브라우저에서 github.com 로그인 → 오른쪽 위 `+` → **New repository**
   - 이름: `pinkpet`, **Public** 선택 → Create repository
2. 만들어진 페이지에서 **uploading an existing file** 클릭
3. 압축을 푼 `pinkpet-android` 폴더 **안의 내용 전부**를 끌어다 놓기
   - `.github` 폴더도 꼭 같이! (맥은 Cmd+Shift+. 로 숨김폴더 보기)
4. 아래 **Commit changes** 클릭
5. 저장소 위쪽 **Actions** 탭 → "APK 만들기"가 돌아감 (3~5분) → 초록 체크 ✅
6. 저장소 오른쪽 **Releases → 진행해줘 펫 최신 버전 → pinkpet.apk**

## 폰에 설치

1. 폰 브라우저(삼성 인터넷/크롬)로 `github.com/ryukoon/pinkpet/releases` 접속 → `pinkpet.apk` 다운로드
2. "출처를 알 수 없는 앱" 허용 → 설치
3. 앱 열기 → ① 다른 앱 위에 표시 권한 ② 알림 권한 ③ 배터리 제한 해제 → **펫 시작!**
4. 삼성 추가 설정: 설정 → 배터리 → 백그라운드 사용 제한 → "사용하지 않는 앱 자동 절전" 끄기 또는 이 앱을 "절전 예외 앱"에 추가

## 사용법
- 톡: "진행해줘!" 인사 / 잡고 던지기: 떨어져서 띠용~
- 꾹 누르기(0.6초): 모션 메뉴 열기
- 모션 14종: 가만히·걷기·달리기·점프·앉기·잠자기·손인사·춤추기·두리번·기지개·펜 칼싸움·몰래 라면·파워업 변신·치킨 변신
- 알림창 [펫 끄기]로 종료

## 참고
- 실제 앱 아이콘 위치는 다른 앱이 알 수 없어서, 바닥(화면 아래)과 양옆 벽을 발판으로 써요.
- 안드로이드 보안 규칙상 효과 창(말풍선·금 간 화면)은 80% 불투명도로 보여요. 그래야 아래 앱이 정상적으로 터치돼요.
- 빌드가 빨간 X로 실패하면 Actions 로그의 에러 부분을 복사해서 Claude에게 보내주세요.
